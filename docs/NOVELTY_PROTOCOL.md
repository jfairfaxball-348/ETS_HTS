# Two-pass novelty audit

Novelty is an **open-world search problem**. A documented absence of located prior art is evidence-limited; it cannot certify first discovery.

## Pass A: shallow triage
Normalise exact quantifiers, objects, edge cases, equivalent formulations and obvious parametrisations. Search distinctive exact phrases, keywords, small parameter values and synonyms with dated queries. Look up OEIS using numerical terms *and* text/keyword searches; search Wikipedia open-problem lists, arXiv, MathOverflow/Math.SE and quick reference indexes. Track an audit row for **each query** (candidate ID, source/database, URL or precise collection, literal string, date/time and timezone, filter, result count or UNKNOWN, snippets vs opened result, inspected SRC IDs, access grade, notes). "No hit" -> SHALLOW_SEARCH_NO_HIT only if reasonable shallow coverage is recorded, otherwise NOT_SEARCHED.

## Pass B: deep audit, mandatory before SURVIVING
Search each candidate's statement rewritten into **2–3 other mathematical languages**: e.g. integers as lattice graphs, forbidden patterns as colourings, games as reachability/strategies; inspect whether reductions work *both directions* including boundary cases. Search the following sources even if domain-specific relevance is weak: OEIS (terms + keyword searches); arXiv full-text (not just metadata); MathOverflow and Math StackExchange; Erdős Problems database; Open Problem Garden; Wikipedia lists of unsolved problems; R. K. Guy, *Unsolved Problems in Number Theory*; Croft–Falconer–Guy, *Unsolved Problems in Geometry*; Brass–Moser–Pach, *Research Problems in Discrete Geometry*; Kourovka Notebook for group theory; Mathematics Magazine and American Mathematical Monthly problem sections; recent 2025–2026 preprints; Zenodo and GitHub research repos. Add disciplinary books/bibliographies and forward/backward references. If a database or book is inaccessible, record attempted exact query, scope, failure and **UNKNOWN** result count; do not claim full coverage. Prioritise original statements and proof pages over snippets.

## Reference and match classification
For every inspected source assign SRC-#### with author, date, URL/DOI, access grade. METADATA_ONLY, ABSTRACT_INSPECTED, STATEMENT_INSPECTED, PROOF_INSPECTED or SECONDARY_ONLY are distinct; a search excerpt remains NOT INSPECTED, even if suggestive. Document closest exact match, known variant, or equivalence with a bidirectional map. KNOWN_EXACT needs an inspected matching statement; KNOWN_VARIANT needs explicit relation and distinction; KNOWN_EQUIVALENT requires a recorded legitimate equivalence, not superficial resemblance. Where nothing found after deep protocol, grade DEEP_SEARCH_NO_HIT and say only: "No prior statement located in the dated, logged searches." Missing access must be prominently disclosed.

## Stop and escalation
Known exact => KILLED_KNOWN; easy proof => KILLED_EASY; counterexample/degeneracy => KILLED_FALSE/DEGENERATE; trivial exact reformulation => KILLED_EQUIVALENT. Interesting nontrivial variants can remain for review but cannot claim first discovery. No public outreach without owner permission. Re-audit near publication because contemporary records move.
